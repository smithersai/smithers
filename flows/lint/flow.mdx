# Lint the named files

The appended arguments name one or more files in this repository. Lint them
against the conventions below, fix what you find, and report what changed.

## Read the files

Read each named file in full with your file tools. Skip a path that does not
exist and say so. Do not call other flows; the work is yours.

## Check the conventions

- Every exported value carries a JSDoc block with `@since` and `@category`.
- No `any`, no non-null `!` assertion without a comment naming why it is safe.
- No `console.log` outside a `bin` entry point.
- Imports are sorted: external packages first, then `@smthrs/*`, then relative.

## Fix and verify

Fix every violation in place with the smallest edit that resolves it. Then run
`pnpm exec eslint <file>` on each changed file through the `bash` tool and
report its output.

## Report

List each file, each violation found, and whether it was fixed. If nothing was
wrong, say so in one line.
