# Security review remediation — 2026-09-14

- Desktop stream mint responses must supply an absolute HTTP(S) URL before the
  app places the URL in an iframe. JavaScript, data, file, and relative URLs fail
  parsing.
- Tutorial executors require the coordinator's session-specific token for every
  `/execute` call. Tokens are compared through fixed-length SHA-256 digests in
  constant time. Missing configuration fails closed; `/health` remains open for
  Kubernetes probes. Local development must also set `TUTORIAL_EXECUTOR_TOKEN`
  and send `x-tutorial-executor-token`.
- Executor pod names include an authentication-version namespace so the updated
  coordinator cannot reuse pre-authentication pods. Old pods retain their existing
  one-hour lifetime; remove old executor pods as part of a security rollout.
- Session mint failures never print the Set-Cookie value. Storage state is written
  at mode 0600 in a private temporary directory beside the destination, then
  renamed atomically. Existing public files and symlinks cannot expose or redirect
  the new cookie. This protects rewrites as well as first-time creation.

Validation: workspace seam tests, session storage regressions (including existing
0644 files and symlinks), and coordinator smoke tests exercising the real executor
HTTP boundary with correct, wrong, and missing tokens. The companion Plue report
records the server fixes, key removal, installer hardening, and DNS review.

These are source changes. No production deployment is performed by this work.
