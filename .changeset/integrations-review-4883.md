`Core.CookieKeys.verify` accepts only the lowercase hex MAC `sign` writes, so the auth broker's single-use `start` check can no longer be replayed with a re-spelled signature. A Connect callback that fails after the code exchange revokes its GitHub token. `GitHub.Auth.permission` validates `owner/repo` before building the request path. `LinkPullRequest` reports a mutation GitHub refused as a definite, non-retried failure. The webhook example ignores a verified non-JSON body, and the receiver guide answers 401, 400 or 500 by failure.
