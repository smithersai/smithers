# Issue tree filing

Each submit, watch and work-link attempt is one recorded action. Transient transport failures (including host fetch timeouts), HTTP 429 and HTTP 5xx return an unfinished outcome. The round waits on `@smthrs/flow`'s durable timer: 2 seconds exponentially to 5 minutes, or a Retry-After delay capped at 5 minutes. Numeric seconds and HTTP dates are accepted. The cursor retains a per-stage budget across submit and pending-watch successes; the twelfth transient failure ends with `unavailable_exhausted`, naming the stage. Older cursors start that budget at zero.

HTTP 401 and 403 stop immediately with `refused`. Permanent shape-lookup refusals follow the same row policy (Electric 409 still resets its shape cursor). Other permanent refusals, including HTTP 400, 404, 409, 413 and 422, fail only that row. The report retains every failed row by key with its stage, status and safe cause; children of a failed parent are skipped, and unrelated rows continue. A settled machine-write failure remains a reported row exception. The run completes with its exceptions. Retries keep the row-key-derived write ID; replaying work links is idempotent. Shape-read outages follow the same round budget. A missing or disconnected shape body is retried before its Electric offset or handle can advance. Identity verification remains a preflight check and must succeed before filing starts.
