Every export mirrors the definition of the same name in the Lean reference
(`lean/MergeQueue/*.lean`).

## Vocabulary (`Basic`)

| Export                                               | Meaning                                                                                                             |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `Part`                                               | One revision of one change: `{ id, rev }`.                                                                          |
| `Tree`                                               | The parts applied to the target, in order.                                                                          |
| `Change`                                             | A change the queue has seen: id, priority, arrival number, revision, fix attempts used, status.                     |
| `Status`                                             | `queued`, `fixing` (with the run that blamed it), `merged`, `unmergeable` (with a `Reason`), `withdrawn`.           |
| `Reason`                                             | Why a change is unmergeable: `kind`, `detail` (never empty), `failures`, `attempts`.                                |
| `Run`                                                | One CI run on one exact tree: `base` followed by `batch`, with streamed `results`.                                  |
| `Landing`                                            | The audit record of one landing.                                                                                    |
| `Config`                                             | `required`, `maxAttempts`, `maxBatch`, `maxRuns`, `window`, `defaultDuration`.                                      |
| `State`                                              | Everything the queue remembers; all of it durable.                                                                  |
| `Event`                                              | `enqueue`, `withdraw`, `result`, `fixed`, `gaveUp`, `foreign`, `land`, `start`, `probe`, `push`, `blame`, `cancel`. |
| `empty`                                              | The queue before anything has happened.                                                                             |
| `part`, `tree`, `samePart`, `sameTree`, `isTerminal` | Accessors and comparisons.                                                                                          |

## Transitions (`Step`)

| Export                                                                     | Meaning                                                                                |
| -------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| `step(config, state, event)`                                               | The queue. Returns the given state when the event's guard fails.                       |
| `run(config, state, events)`                                               | Applies events in order.                                                               |
| `enqueue`, `withdraw`, `result`, `fixed`, `gaveUp`, `foreign`, `land`      | The events that arrive from outside. `land` is accepted only for the run being pushed. |
| `start`, `probe`, `push`, `blame`, `cancel`                                | The queue's decisions. `probe` tests one ready change alone on the tip.                |
| `pushingRun`, `pushingPart`, `landNow`, `withdrawNow`, `fixedNow`          | The push under way, and the inner steps `land`, `withdraw` and `fixed` guard.          |
| `answered`, `passed`, `failed`, `complete`, `green`, `failures`, `pending` | Reading a run's results. `green` is the only result that lets a tree land.             |
| `before`, `inOrder`, `ready`                                               | Landing order: priority, then arrival.                                                 |
| `strip`, `partReady`, `live`                                               | Whether a run can still land or blame.                                                 |
| `pendingCount`, `findRun`, `failuresOf`, `record`, `exhaustedDetail`       | Counting, lookup and bookkeeping.                                                      |

## Policy (`Policy`)

| Export                                                                                                                                                              | Meaning                                                                                                          |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `plan(config, state)`                                                                                                                                               | The next decision, or `undefined` when the queue waits for the world.                                            |
| `settle(config, fuel, state)`                                                                                                                                       | Applies decisions until there is none, at most `fuel` times.                                                     |
| `landable`, `nextPush`, `blameable`, `evidence`, `doomed`, `useless`, `outOfOrder`                                                                                  | Why `plan` pushes, blames, keeps, cancels or waits.                                                              |
| `prefixLength`, `failedPrefixes`, `unfailedPrefixes`, `shortestFailed`, `longestUnfailed`, `nextStart`, `bisectStep`, `nextProbe`, `bestLandable`, `minOf`, `maxOf` | Speculation, parallel bisection and probes.                                                                      |
| `wantsCi(config, state, run)`                                                                                                                                       | Whether CI should be running a run.                                                                              |
| `fixBriefs(state)`, `ahead(state, change)`, `FixBrief`, `Ahead`                                                                                                     | What each fix agent is given: revision, attempt, failures so far, and the changes ahead with who is fixing them. |

## What the queue keeps (`Compact`)

| Export                                                                                      | Meaning                                                                                                                                                 |
| ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `pruned(state)`                                                                             | The state without the changes that ended and without the landings. This is what a driver carries between rounds.                                        |
| `fresh(state, event)`                                                                       | Whether the event keeps the rule that a change id is never used again: it is not an `enqueue` or a `foreign` commit for the id of a change that ended.  |
| `settled(state)`, `cut(state, count)`                                                       | How many parts of the target's tree every run was built on, and the state with that many parts cut from the target's tree and from every run's base.    |
| `runPruned(config, state, events, dropped?)`, `settlePruned(config, fuel, state, dropped?)` | `run` and `settle` for the queue that keeps only the pruned state: prune after every event. `dropped(before, after)` sees each step before its pruning. |

## Predicted durations (`Predict`)

| Export                                | Meaning                                 |
| ------------------------------------- | --------------------------------------- |
| `samples(history, check)`             | A check's remembered durations.         |
| `estimate(config, history, check)`    | Their median, or `defaultDuration`.     |
| `schedule(config, history)`           | The required checks, slowest first.     |
| `remaining(config, history, results)` | The checks of a run with no result yet. |
| `eta(config, history, results)`       | The slowest remaining check's estimate. |

## Traces (`Trace`)

| Export                                             | Meaning                                             |
| -------------------------------------------------- | --------------------------------------------------- |
| `parseLine(text)`                                  | Reads one trace line: a config, an event or `plan`. |
| `renderEvent(event)`, `renderState(config, state)` | The lines the reference prints.                     |
| `apply(config, state, line)`, `replay(lines)`      | Runs trace lines.                                   |
| `Line`, `initialConfig`                            | The parsed line and the config a trace starts from. |

## Driver (`Driver`) and services

| Export                                                                                                                                                                         | Meaning                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Driver.round(config, position)`                                                                                                                                               | One round: record the endings of the round before, sync, gather (waiting when idle), fold, check the tip, cut the settled parts. Returns the next `Position` (its pruned and cut state, and `settled`, the parts cut so far), the changes it `ended` and `done`.                                                                                                                                                                                                                                   |
| `Driver.sync(commands)`, `Driver.commands(config, state, from?)`                                                                                                               | Make the world match a state. `Commands` is the parts the target must have settled, the fast-forward under way, the wanted CI jobs and the fix briefs. `from` is `Position.settled`.                                                                                                                                                                                                                                                                                                               |
| `Driver.gather`, `Driver.waitForNews`, `Driver.tipEvents`                                                                                                                      | Reading the world; `tipEvents` turns the target's tip into `land` and `foreign` events.                                                                                                                                                                                                                                                                                                                                                                                                            |
| `Driver.advance`, `Driver.drained`, `Driver.ended`, `Driver.job`, `Driver.settleFuel`                                                                                          | Folding events into the pruned state (returns the next state and the changes that ended), the finished test, the changes that ended between two states, a run's CI job.                                                                                                                                                                                                                                                                                                                            |
| `Inbox`, `Ci`, `Fixer`, `Target`, `Endings`                                                                                                                                    | The services a host provides. `Target.advance(from, to)` is a compare-and-swap fast-forward; `Target.settle(count)` makes the target speak of trees from `count` parts after the queue's start. `Endings.record(endings)` keeps how each change ended; recording a change twice records it once.                                                                                                                                                                                                   |
| `Letter`, `Job`, `Finished`, `Progress`, `Answer`, `Ending`                                                                                                                    | What those services carry. A `Job` names its tree from `from` settled parts. An `Ending` is a change's last revision, attempts and final status, with the landing of a merged change.                                                                                                                                                                                                                                                                                                              |
| `Unavailable`, `TargetDiverged`                                                                                                                                                | A service could not answer; the target's tip does not extend the tree the queue knows.                                                                                                                                                                                                                                                                                                                                                                                                             |
| `QueueSchema`                                                                                                                                                                  | Effect schemas for `State`, `Config`, `Event` and their parts.                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `QueueFlow.Queue`, `QueueFlow.Round`, `QueueFlow.layer`                                                                                                                        | The queue as a durable flow: one recorded action per round, the next position as the next round's payload. One run is one lineage; it succeeds with `QueueFlow.End` when the lineage ends.                                                                                                                                                                                                                                                                                                         |
| `QueueFlow.Payload`, `QueueFlow.Outcome`, `QueueFlow.End`, `QueueFlow.next`, `QueueFlow.lineageRounds`, `QueueFlow.RoundError`, `QueueFlow.retryPolicy`, `QueueFlow.maxRounds` | Its schemas; `End` is `{ done, position }`, the next lineage's start value; `Payload.lineage` is the rounds one lineage runs (default 200); the unbounded retry of a failed round; the engine's own round bound.                                                                                                                                                                                                                                                                                   |
| `FileInbox.layer({ path, poll })`, `FileInbox.append(path, line)`, `FileInbox.Line`                                                                                            | The `Inbox` over a JSON-lines file, on Effect's `FileSystem`. A line that is not a letter is passed over and still counts toward the cursor.                                                                                                                                                                                                                                                                                                                                                       |
| `FileEndings.layer({ path })`, `FileEndings.record(path, endings)`, `FileEndings.read(path)`, `FileEndings.Line`                                                               | The `Endings` record as a JSON-lines file: one line per ended change with the time it was written. A change the file holds is not written again.                                                                                                                                                                                                                                                                                                                                                   |
| `Handover`, `FileHandover.layer({ path })`, `FileHandover.save(path, handover)`, `FileHandover.read(path)`, `FileHandover.Document`                                            | Where a lineage leaves `{ done, position }` when it ends. The file adapter replaces one JSON document by rename, so a host reads the old position or the new one, never half.                                                                                                                                                                                                                                                                                                                      |
| `JjRepository.make(options)`, `JjRepository.target(repository, poll)`, `JjRepository.Candidate`, `JjRepository.Ledger`, `JjRepository.firstForeign`                            | The target as a local jj bookmark. `candidate(tree, from)` replays each change's commit onto the tip, one ledger entry per part applied on a commit; `advance` moves the bookmark onto the tested commit; `settle(count)` moves the ledger's starting commit forward and drops what only the settled parts needed. `options.parallel` (default 1) is how many changes are replayed and finished at once; one application runs per commit and change, and builders that need the same one share it. |
| `CommandCi.layer({ repository, command, poll })`, `CommandCi.Command`                                                                                                          | The `Ci` as one process per check on the candidate commit. Exit 0 passes, any other exit fails; a change that does not apply fails every check; a check that cannot start, or a stale tree, loses the run and blames nobody.                                                                                                                                                                                                                                                                       |
| `CommandCi.streamed({ repository, command, poll })`                                                                                                                            | The `Ci` as one process per run, such as one `smthrs ci`. The process prints `<check> pass` or `<check> fail`, with optional seconds, as each check finishes; other lines are ignored. A process that ends with a check unreported loses the run.                                                                                                                                                                                                                                                  |
| `CommandFixer.layer({ repository, directory, command, poll })`, `CommandFixer.AnswerFile`                                                                                      | The `Fixer` as one process per change being fixed. The brief is a file, rewritten as failures stream in; the agent answers by writing an answer file. A `fixed` answer registers the new revision's commit first. An agent that exits without a readable answer is started again; an answer is never invented.                                                                                                                                                                                     |
