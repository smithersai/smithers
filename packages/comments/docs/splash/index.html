Agentic comment workflows

Smithers Comments

Keep comments accurate inline, or store them in .comments/ and project commented virtual files with Smithers workflows.

Docs Source

Validate comments in any repository

bunx smithers-comments check

Or move comments out of source files

bunx smithers-comments extract

How it works

  1. Parse

    Reads comments across TypeScript, Python, Go, Rust, SQL, and more without touching strings, regexes, or compiler pragmas.

  2. Anchor

    Binds each comment to its symbol, line, or pattern plus a SHA-256 hash of the anchored code region.

  3. Validate & cache

    Runs structural checks and agentic verification inside a cached Smithers flow. Unchanged comments cost zero model calls.

  4. Project

    In external mode, weaves .comments/ back into source files as a Smithers virtual file overlay or materialized directory.

Two modes

mode: "inline"

Inline mode

Comments live in your source files. Smithers continuously lints structure, verifies symbol references, and runs cached agent checks whenever a comment or the code beneath it changes.

mode: "external"

External mode

Source files stay clean of prose comments while pragmas remain intact. Comments live in .comments/ (or any configured folder), and Smithers virtual files generate commented files on demand.

// PACKAGE.ts
import { Smithers } from "@smthrs/targets"
import { targets } from "smithers-comments"

const comments = targets({
  mode: "external",
  commentsDir: ".comments",
  include: ["src/**/*.ts"]
})

export const Package = Smithers.Package({
  targets: { ...comments }
})

Commands

smithers-comments init
Configure inline or external mode, comments folder, and Smithers targets.
smithers-comments check
Lint and validate comments incrementally using Smithers caching. Alias: lint.
smithers-comments fix
Run the agentic workflow to update stale comments or re-anchor drifted entries.
smithers-comments extract
Move inline comments into .comments/ while preserving compiler and linter pragmas.
smithers-comments render
Generate commented virtual files to stdout, an output directory, or back in place.
smithers-comments status
Show active mode, comment counts, anchor health, and cache hit statistics.
