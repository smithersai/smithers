# Stage 4 Architectural Review & Synthesis: Gemini vs. Claude Fable vs. Codex Astra

Three independent implementations of **Smithers Comments** were built strictly from the same Stage 1–3 contract (`docs/` + `test/` + `BUILDER_BRIEF.md`) with zero visibility into each other's code, then compiled, fuzzed (`@smthrs/fuzz`, 3,800 executions), property-tested (`Arbitrary.checkEffect`), end-to-end CLI tested, and benchmarked on `nyc-01` (Node 26.5.0, Effect 4.1.1, Smithers `1.0.0-rc.18`).

## Resolved Design Decisions

| Subsystem                                     | Gemini Position                                                                 | Claude Fable Position                                                                                                                                                  | Codex Astra Position                                                                                                                               | Final From-Scratch Choice & Evidence                                                                                                                                                                                                                                                                                                 |
| --------------------------------------------- | ------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Lexer inner loop**                          | Single-pass indexed scanner without inner-loop regex slicing (13.2 MB/s)        | Thorough multi-language scanner + `hasLineComments` for CSS + `removeSpans`                                                                                            | Added Rust raw strings `r#"..."#` + mid-line token-glue spacing (`foo/*x*/bar` → `foo bar`), slower inner-loop `.slice()` regexes (4.4 MB/s)       | **Gemini's fast indexed loop + Astra's Rust raw strings & token-glue spacing + Fable's `hasLineComments` & `removeSpans`.** Keeps >13 MB/s speed while closing every edge case.                                                                                                                                                      |
| **Symbol extraction & code regions**          | Line regex scan over raw text; fixed 5-line code window                         | Broad multi-language rules + `paramsComplete` flag (avoids false positives on destructuring)                                                                           | Masks out comments before symbol extraction (zero false symbols in comments); stops code region at next top-level declaration                      | **Astra's comment-masking + declaration-bounded regions + Fable's `paramsComplete` + per-file `SourceIndex` caching.** Eliminates false cache invalidations and keeps projection under 20 ms.                                                                                                                                        |
| **Sidecar escaping & paths**                  | Single backslash escape `\## @`; simple POSIX normalize                         | Strict canonical header parser + `sortEntries` helper                                                                                                                  | Arbitrary-depth backslash escaping (`^(\*)## @` → `\$1## @`) + `safeRelative` confinement                                                          | **Astra's arbitrary-depth escaping & `safeRelative` + Fable's `sortEntries` for extract/fix.** Guarantees lossless round-trips even for bodies containing literal `\## @`.                                                                                                                                                           |
| **Virtual file projection & materialization** | Clean `Effect.gen` projector; direct `writeFile`                                | Pure `projectFileSync` (19.8 ms); converts `*/`-bearing block comments to `//` or `* /`; escapes `-->`                                                                 | `confinedPath` symlink traversal guard + `atomicWrite` (temp + rename, preserving mode) + skip-unchanged writes                                    | **Fable's pure `projectFileSync` + safe delimiter escaping + Astra's `confinedPath` & `atomicWrite`.** Fastest projection plus crash-safe, traversal-safe disk writes.                                                                                                                                                               |
| **DocTags & Heuristic Validator**             | Simple `@ref`/`@param` regex + basic tautology regex                            | Dedicated `DocTags.ts` with `withoutInlineCode` (ignores backtick mentions) + `repairParamTags` + camelCase/operator-synonym `restatesCode` + real `commandAgentLayer` | Detects single-return literal contradictions (`returns true` vs `return false`) + file-path `@ref` checks + fail-closed `agent: "smithers"` on CLI | **Fable's `DocTags.ts` + `restatesCode` + `commandAgentLayer` + Astra's return-value contradiction check, path `@ref` validation, and fail-closed CLI.**                                                                                                                                                                             |
| **Repair & Extraction**                       | Basic inline replacement + fresh extract overwrite                              | Dedicated `Repair.ts` with automatic `reanchor` by unique `codeHash` + conservative hash refresh + empty sidecar deletion                                              | Merges into existing sidecars during `extract` with deduplicated IDs + atomic rollback if source write fails                                       | **Fable's `reanchor` & conservative hash refresh + Astra's merge-preserving atomic extract with rollback.**                                                                                                                                                                                                                          |
| **Smithers Flows & Caching**                  | Declared `@smthrs/flows` actions/flows + direct cache loop (8.5 ms warm, 30.8×) | True declarative `@smthrs/plan` DAG (`Node.branch` on `LookupVerdictAction` → `CheckCommentAction` → `StoreVerdictAction`) executed on `FlowEngine` (110 ms warm)      | Executes `CheckFileFlow`/`CheckCommentFlow` via `FlowEngine.layerMemory` (217 ms warm; O(N·M) re-lexing)                                           | **Fable's declarative `@smthrs/plan` DAG (`CheckFileFlow`, `FixFileFlow`, `RenderVirtualFlow`) over `FlowEngine.layerMemory`, PLUS an O(1) warm-file cache pre-check in `runCheckRepository`** so warm runs bypass engine startup (~10 ms, 25×+ speedup) while every cache miss and fix executes through the real Smithers Flow DAG. |

## Test Compatibility Findings Resolved During Stage 4

Both Codex Astra and our independent validation caught two Effect 4.1.1 / Vitest harness mismatches in the initial Stage 3 draft tests (documented in `implementations/astra/NOTES.md`):

1. Effect 4.1.1 exposes `Arbitrary.schema` + `Arbitrary.checkEffect` (not `Arbitrary.make` / `effect/testing/FastCheck`), and `@smthrs/fuzz` `Fuzz.observe(label)` takes one label string. Updated `test/properties.test.ts` and `test/fuzz.test.ts` accordingly without weakening any property or fuzz assertion.
2. `test/comments.benchmark.test.ts` used `it.effect` (virtual `TestClock`) around `Effect.sleep("2 millis")`; switched that benchmark to `it.live` so it measures real wall time.
