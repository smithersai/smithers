Fast CI for agents

Smithers CI

Give your agent a faster CI feedback loop with incremental, cached runs.

Docs Source

In a repository

bunx smithers-ci

How it works

  1. Read

    Your CI: GitHub Actions, Justfile, Makefile, package.json, Turborepo.

  2. Cache

    A step reruns only when a file it reads changes.

  3. Replay

    Runs your past commits both ways: your CI, and cached.

  4. Report

    The time each way, and every result that differs.

Two modes

Normal mode

Runs everything a change affects. Same results as your CI.

Fast mode

Also skips tests a model predicts the change cannot break. A skip is reported as a skip, never as a pass.

Commands

bunx smithers-ci
Replay past commits and print the speedup. Changes nothing.
bunx smithers-ci inventory
Print what your CI runs.
bunx smithers-ci replay
The replay alone.
bunx smithers-ci apply
Write the cached CI into the repository.
