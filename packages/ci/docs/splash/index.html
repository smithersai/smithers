How it works

No migration to a proprietary YAML dialect. Point Smithers CI at your repository and measure exact parity on real commits first.

  1. Read

    Parses GitHub Actions, Justfile, Makefile, package.json scripts, and Turborepo into an explicit inventory.

  2. Cache

    smthrs-observe traces exact file reads inside bubblewrap; a step reruns only when an input it read changes.

  3. Replay

    Replays recent commits in isolated copies both ways — baseline CI vs cached — without touching your checkout or $HOME.

  4. Report

    Prints wall time, CPU seconds, why every step ran or hit cache, and flags every differing verdict immediately.

Two modes

Strict cryptographic parity by default, with opt-in predictive test selection when you want an even shorter agent loop.

Default · Zero stale passes

Normal mode

Runs every target whose recorded inputs changed and reuses a result only when every read file, directory entry, and env dependency matches. Same results as your CI.

Opt-in · Honest reporting

Fast mode

Also skips tests a model predicts the change cannot break (via AI_GATEWAY_API_KEY or a signed-in Claude/Codex CLI). A skip is always reported as a skip, never as a pass, and never written to cache.

Measured on real repositories

Every number below comes from real packed-tarball replays with zero mocked processes. When a repository reuses too little to win, Smithers CI prints that plainly too.

Why you can trust the cache

CI caches fail silently when a tool reads an undeclared file, calls a local daemon, or mutates an input in place. Smithers CI treats unsoundness as a release blocker.

Kernel-level observation (smthrs-observe)

Compiled C supervisor using Linux seccomp USER_NOTIF (with strace fallback). Tracks all 104 file/network syscalls, refuses io_uring, detects unconnected UDP/Unix sends to external daemons, records directory link counts, and keeps job background servers alive only for their job's lifetime.

Isolated, tamper-checked execution

Every job runs in its own bubblewrap jail with an isolated $HOME and non-pushable Git config. Content-addressed store verified against 7 tampering attacks with 0 stale passes. Untrusted repositories replay strictly inside Cloudflare Sandboxes via box-replay.mjs.

Commands

bunx smithers-ci
Replay recent commits and print the speedup. Changes nothing in your repository.
bunx smithers-ci inventory
Print every job, step, and unsupported action parsed from your CI.
bunx smithers-ci replay --commits 5
Run the replay on the last 5 commits (add --mode both for fast mode).
bunx smithers-ci apply
Write .smithers/WORKSPACE.smithers and .github/workflows/smithers-ci.yml when you trust the replay.
