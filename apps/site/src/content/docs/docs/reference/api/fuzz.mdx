`@smthrs/fuzz` exports two namespaces from its root entry point:

```ts
import { Fuzz, FuzzSimulation } from "@smthrs/fuzz"
```

`@smthrs/fuzz/package.json` is exported. `@smthrs/fuzz/internal/*` is not. `effect` 4.1.1 is a peer dependency. The
[fuzzing guide](https://github.com/smithersai/smithers/blob/main/packages/fuzz/docs/README.md) explains when to fuzz,
how feedback guides the search, and how saved failures replay in Vitest.

## Example

```ts
import { Fuzz } from "@smthrs/fuzz"
import { Arbitrary, Effect, Schema } from "effect"

const byte = Schema.Int.check(Schema.isBetween({ minimum: 0, maximum: 255 }))
const parse = (bytes: ReadonlyArray<number>) =>
  Effect.gen(function*() {
    if (bytes[0] !== 0x7f) return true
    yield* Fuzz.observe("magic 1")
    if (bytes[1] !== 0x45) return true
    yield* Fuzz.observe("magic 2")
    return bytes[2] !== 0x4c
  })

const report = await Effect.runPromise(
  Fuzz.run(Arbitrary.schema(Schema.Array(byte)), parse, { seed: 1, executions: 200_000 })
)
report._tag // => "Falsified"
```

The property contract is `Arbitrary.checkEffect`'s: return `true`, or an Effect of `true`, to pass. Returning anything
else, failing or dying is a finding. Interruption propagates. The property must give the same outcome for the same
input and must not mutate its input.

## Module reference

### `Fuzz`: running

| Export         | Signature                                                                       | Behavior                                                                                                                                                                 |
| -------------- | ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `run`          | `(arbitrary, property, options?) => Effect<Report<A, E>, FuzzError, R>`         | Fuzzes a property with an in-memory corpus. Without `duration`, `executions` or `plateau`, the budget is 10 seconds of wall time.                                        |
| `runTarget`    | `(self: Target<A, E, R>, options?) => Effect<Report<A, E>, FuzzError, R>`       | Replays the target's saved failures and inputs from the `Corpus` store, then searches. New failures are saved after shrinking and confirmation.                          |
| `target`       | `(schema \| arbitrary, property, options: TargetOptions<A>) => Target<A, E, R>` | Names a property for a corpus store. A Schema input gets a value codec from `Schema.toCodecJson`; an Arbitrary input saves tapes unless `options.codec` is given.        |
| `formatReport` | `(report: Report<A, E>) => string \| undefined`                                 | A diagnostic for every report except `Passed`, which answers `undefined`. Names each feedback source; a run with only structural features says "structural exploration". |

### `Fuzz`: options and targets

| Export          | Signature                                                                                                       | Behavior                                                                                                                                                                                                                                                                                        |
| --------------- | --------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Options`       | `{ seed?, duration?, executions?, plateau?, size?, maxShrinks?, maxFindings?, feedback?, execution?, replay? }` | The first of `duration`, `executions` and `plateau` stops the run. `executions: 0` only replays saved failures. `size` defaults to 100, `maxShrinks` to 1000, `maxFindings` to 1, `feedback` to `[Fuzz.spans]`. `replay` replays one finding and ignores every other option except `execution`. |
| `Target`        | interface `{ id, revision }`                                                                                    | A property and the identity a corpus stores it under. Built by `target`.                                                                                                                                                                                                                        |
| `TargetOptions` | `{ id: string; revision: string; codec?: Codec<A> }`                                                            | `id` names the corpus. Change `revision` when the Arbitrary changes; saved tapes of another revision stop replaying. Saved values survive every revision.                                                                                                                                       |
| `Codec`         | `{ id: string; encode: (value: A) => string; decode: (text: string) => A }`                                     | Saves a failure as a value. A decode error or another codec id is a `Codec` `FuzzError`; an encode error falls back to a tape and sets `Finding.codecError`.                                                                                                                                    |
| `Replay`        | `string`                                                                                                        | An opaque token holding a finding's generator tape, schedule tape, shrink path and signature. Tied to its generator.                                                                                                                                                                            |

### `Fuzz`: reports and findings

| Export           | Signature                                                                                     | Behavior                                                                                                                                                                                                                  |
| ---------------- | --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Report`         | `Passed \| Falsified<A, E> \| Flaky<A, E> \| Exhausted \| ReplayMismatch`                     | The result of a run.                                                                                                                                                                                                      |
| `Passed`         | `{ _tag: "Passed"; stats }`                                                                   | No findings.                                                                                                                                                                                                              |
| `Falsified`      | `{ _tag: "Falsified"; findings: NonEmptyReadonlyArray<Finding>; flaky; stats }`               | Distinct confirmed failures, plus any flaky ones.                                                                                                                                                                         |
| `Flaky`          | `{ _tag: "Flaky"; flaky: NonEmptyReadonlyArray<FlakyFinding>; stats }`                        | Every failure gave a different outcome when evaluated again.                                                                                                                                                              |
| `Exhausted`      | `{ _tag: "Exhausted"; stats }`                                                                | Every execution was discarded; no exploratory evaluation completed.                                                                                                                                                       |
| `ReplayMismatch` | `{ _tag: "ReplayMismatch"; stats }`                                                           | A replay token's tape discarded or its shrink path no longer exists.                                                                                                                                                      |
| `Finding`        | `{ signature, failure, input, initialInput, shrinks, execution, replay, saved, codecError? }` | One distinct failure. `signature` is `ReturnedFalse`, `PropertyError:<name>`, `Died:<name>` or `Deadlock`. `execution` is `0` for a saved failure and `1` for a replay token. `saved` is `"Value"`, `"Tape"` or `"None"`. |
| `FlakyFinding`   | `Finding & { recheck: Outcome<E> }`                                                           | A failure whose second evaluation on the same input differed. Not saved as a fixture.                                                                                                                                     |
| `Failure`        | `Arbitrary.ReturnedFalse \| Arbitrary.PropertyError<E> \| Died \| Deadlock`                   | Why a property was falsified.                                                                                                                                                                                             |
| `Outcome`        | `Failure<E> \| { _tag: "Passed" } \| { _tag: "Limited" }`                                     | One evaluation's result. `Limited` means a simulated execution reached its step limit.                                                                                                                                    |
| `Died`           | `{ _tag: "Died"; defect: unknown }`                                                           | The property died, or failed with an empty cause (signature `Died:EmptyCause`).                                                                                                                                           |
| `Deadlock`       | `{ _tag: "Deadlock" }`                                                                        | A simulated execution ran out of runnable work while the property was still running.                                                                                                                                      |
| `Stats`          | `{ seed, executions, discards, corpus, features, regressions, stale, stoppedBy }`             | `features` counts distinct features per feedback source. `stoppedBy` is `"Duration"`, `"Executions"`, `"Plateau"`, `"Findings"` or `"Replay"`.                                                                            |
| `FuzzError`      | class `new ({ reason, message, cause? })`, `_tag: "FuzzError"`                                | A failure of the fuzzing machinery, not the property. `reason` is `Configuration`, `Corpus`, `Generation`, `Feedback`, `Execution` or `Codec`.                                                                            |

### `Fuzz`: feedback

| Export     | Signature                                                                           | Behavior                                                                                                                                 |
| ---------- | ----------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `spans`    | `Feedback`                                                                          | Records a `(parent span, span)` edge for every span an execution starts, so `Effect.fn("name")` code is a coverage point. On by default. |
| `observe`  | `(label: string) => Effect<void>`                                                   | Records that an execution reached a stage. Does nothing outside a fuzz execution.                                                        |
| `score`    | `(label: string, value: number) => Effect<void>`                                    | Records a value the search maximizes per label. Does nothing outside a fuzz execution.                                                   |
| `Feedback` | `{ name: string; measure: (self: Effect<A, E, R>, sink: Sink) => Effect<A, E, R> }` | A feedback source wrapping one execution. A defect raised by `measure` is a `Feedback` `FuzzError`.                                      |
| `Sink`     | `{ feature: (key: string \| number) => void }`                                      | Receives one execution's features. Repeated features count hits in buckets 1, 2, 3, 4-7, 8-15, 16-31, 32-127 and 128 or more.            |

### `Fuzz`: corpus and execution

| Export            | Signature                                                                                                               | Behavior                                                                                                   |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `Corpus`          | `Context.Reference<Store \| undefined>`                                                                                 | The store `runTarget` reads and writes. Defaults to none: the corpus lives in memory for one run.          |
| `memoryCorpus`    | `() => Store`                                                                                                           | A store that keeps entries in memory, shared by every run that uses it.                                    |
| `Store`           | `{ load: (target) => Effect<ReadonlyArray<StoredEntry>, FuzzError>; save: (target, entry) => Effect<void, FuzzError> }` | Persists entries per target id. `save` replaces an entry with the same target, kind and key.               |
| `StoredEntry`     | `{ kind: "Input" \| "Failure"; key: string; text: string }`                                                             | `Failure` entries are regression fixtures to commit; `Input` entries are a search cache.                   |
| `Execution`       | `{ name: string; run: (self, schedule: ScheduleTape) => Effect<ExecutionResult, never, R> }`                            | Runs one property evaluation. The default runs it as is.                                                   |
| `ExecutionResult` | `{ _tag: "Completed"; exit } \| { _tag: "Deadlock" } \| { _tag: "Limited" }`                                            | `Deadlock` becomes a finding. `Limited` is a discard during search and an `Execution` error during replay. |
| `ScheduleTape`    | `{ next: () => number }`                                                                                                | Supplies the next 32-bit schedule word to an `Execution`.                                                  |

### `FuzzSimulation`

| Export      | Signature                                           | Behavior                                                                                                                                                                                                                                                                                                                 |
| ----------- | --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `execution` | `(options?: Options) => Fuzz.Execution`             | Runs each evaluation in a closed world: one priority/FIFO scheduler, preemption points read from the schedule tape, and a virtual clock. Pass it as `Fuzz.Options.execution` to find races, lost updates, deadlocks and timeout ties. Real I/O, native timers, `Date.now`, `Math.random` and outside promises escape it. |
| `Options`   | `{ maxSteps?: number; maxOpsBeforeYield?: number }` | `maxSteps`, default 100,000, bounds dispatched tasks and timer wakes per evaluation; cleanup gets another `maxSteps`. `maxOpsBeforeYield`, default 2048, is the slice length for schedule word 0.                                                                                                                        |
