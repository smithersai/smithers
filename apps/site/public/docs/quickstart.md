# Quickstart

> Open a repository on smithers.sh, read its files and issues, and sign in with GitHub.

This page takes you from the smithers.sh home page to a repository's files and issues, then to signing in with GitHub. It takes about five minutes.

**Before you start:** you need a GitHub account to sign in. To open a private repository, you also need read access to it on GitHub.

## 1. Open smithers.sh

Go to [smithers.sh](https://smithers.sh). Choose **Get started for free** to sign in, or open a repository below.

![The smithers.sh home page with Get started for free](https://smithers.sh/images/docs/welcome-home.light.webp)

## 2. Open a repository

A repository on smithers.sh has the path it has on GitHub: replace `github.com` with `smithers.sh` in the repository's address. For example, `https://smithers.sh/smithersai/vibelang` opens the `smithersai/vibelang` repository.

The repository opens on **Home**. Choose **Code** to browse its files and select a branch.

![The smithersai/vibelang repository on its Home tab](https://smithers.sh/images/docs/quickstart-repo-home.light.webp)

A repository not yet cloned offers **Sign in to clone**. A missing or inaccessible repository shows **Not found**; a failed lookup shows an error.

## 3. Read a file

Choose **Code**, then a folder to open it, or a file to read it. The file's path is at the top. Choose the repository's name in the path to go back to its files.

![package.json in smithersai/vibelang on smithers.sh, with the file's path at the top (1)](https://smithers.sh/images/docs/quickstart-file.light.webp)

## 4. Read issues and pull requests

Choose **Issues** to list the repository's open and closed issues, or **Pull requests** to list its pull requests. Choose an issue to read it.

![The Issues tab of smithersai/vibelang on smithers.sh: Issues (1) and Pull requests (2), with each issue's author hidden](https://smithers.sh/images/docs/quickstart-issues.light.webp)

## 5. Sign in with GitHub

From the home page, choose **Get started for free**. GitHub asks you to sign in, then to authorize Smithers to read your account and email address and to access your repositories.

![GitHub's sign-in page, opened from Sign in on smithers.sh](https://smithers.sh/images/docs/quickstart-sign-in.light.webp)

## Result

You opened a repository on smithers.sh, read a file, listed its issues, and started signing in with GitHub.
