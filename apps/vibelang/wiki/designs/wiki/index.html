Decisions 0014 agent-tour

0014. Learn more is a tour the agent drives

Accepted 2026-11-07

Decision. The splash's primary action is Learn more; Ask the agent (⌘K) and Contribute are secondary. Learn more turns the page into the chat, and the agent tours VibeLang: it opens VibeLang's docs in a pane of the conversation, says what each page is, and moves the pane as it goes. While it drives, a glow surrounds the screen and an Esc button shows; Escape or Esc ends the tour at once.

  • The state machine. A tour is an agent entry that answers no post, so it streams, finishes and fails as a reply does, and while it runs the agent is working.
  • Live and mock run the same tour. The stops are STOPS; the mock's speaker says the script's words.
